# Plan 05-02: Window Display with GDI Rendering

## Goal
Create winit-based window and render RGBA frames using GDI StretchDIBits with proper color conversion.

## Requirements
- VIEW-02: Received frames displayed in Win32 windows using GDI

## Must Haves (Goal-Backward Verification)
- [ ] winit 0.30 ApplicationHandler manages window lifecycle
- [ ] Window displays at correct dimensions from frame header
- [ ] RGBA converted to BGRA before GDI rendering (no color swap)
- [ ] StretchDIBits renders frame with correct aspect ratio
- [ ] Window visible with no tearing (double-buffered updates)


2. **Test with synthetic frames:**
   - Create test pattern (gradient, solid colors)
   - Verify colors display correctly (no R/B swap)

3. **Visual inspection:**
   - No tearing during rapid frame updates
   - Correct aspect ratio maintained
   - Window visible and interactive

## Pitfalls Addressed

| Pitfall | Solution |
|---------|----------|
| RGBA vs BGRA color swap | Explicit R↔B channel swap before StretchDIBits |
| Upside-down image | Negative biHeight for top-down DIB |
| GDI handle leak | RAII pattern for GetDC/ReleaseDC |
| Window freeze | Async frame delivery via channel |
