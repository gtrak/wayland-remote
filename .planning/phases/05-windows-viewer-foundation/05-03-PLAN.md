# Plan 05-03: Integration - TCP to Display Loop

## Goal
Connect network client to display window, creating end-to-end frame streaming from Linux server to Windows viewer.

## Requirements
- VIEW-01: Windows application connects to TCP server
- VIEW-02: Received frames displayed in Win32 windows using GDI

## Must Haves (Goal-Backward Verification)
- [ ] Main entry point parses server address from CLI args
- [ ] Network thread spawns and connects to server
- [ ] Frames flow from TCP → channel → window → GDI display
- [ ] At least one window visible showing live remote content
- [ ] Colors correct (no swap), dimensions match source

## Integration Architecture

```
┌─────────────────┐     mpsc      ┌──────────────────┐
│   Network Thread │ ───────────▶ │   Main Thread    │
│  (Tokio Runtime) │   Frame      │ (Winit Event Loop│
│                  │              │                  │
│  TcpClient::     │              │  ViewerApp::     │
│   read_frame()   │              │   window_event() │
└─────────────────┘              └────────┬─────────┘
       ▲                                  │
       │                                  │
       └──────────────────────────────────┘
                        StretchDIBits()
```
