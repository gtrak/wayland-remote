# Plan 05-01: TCP Client Foundation

## Goal
Establish async TCP connection to Linux server and implement frame protocol parsing.

## Requirements
- VIEW-01: Windows application connects to TCP server

## Must Haves (Goal-Backward Verification)
- [ ] TCP client connects to server on configurable address:port
- [ ] 20-byte frame header parsed correctly (window_id, width, height, timestamp)
- [ ] RGBA payload read based on header dimensions
- [ ] Network thread spawned separately from UI thread
- [ ] Frames sent to main thread via channel for display

## Verification Steps

1. **Unit test protocol parsing:**
   ```bash
   cargo test -p viewer protocol::tests
   ```

2. **Integration test with mock server:**
   - Create test server sending known frames
   - Verify client receives and parses correctly

3. **Connection test:**
   - Start Phase 4 server on Linux
   - Connect viewer, verify TCP handshake succeeds
   - Check frames arrive in channel

## Risk Mitigation

| Risk | Mitigation |
|------|------------|
| Blocking UI thread | Use separate Tokio thread with mpsc channel |
| Partial frame reads | Use read_exact, not read |
| Network errors | Implement reconnection logic, error propagation |
| Byte order issues | Explicit big-endian decoding per protocol spec |
