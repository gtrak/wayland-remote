    Create the workspace root Cargo.toml with:

       - members = ["crates/server", "crates/viewer"]

       - edition = "2021" (using 2021 for stability, not 2024 which is too new)

       - license = "MIT OR Apache-2.0"
       - rust-version = "1.70"
       - repository = "https://github.com/wayland-remote/wayland-remote"
    
    3. [workspace.dependencies] with:
       - tokio = { version = "1.40", features = ["full"] }
       - tracing = { version = "0.1", features = ["max_level_trace", "release_max_level_debug"] }

       - thiserror = "1.0"

       - winit = { version = "0.30", default-features = false, features = ["rwh_06"] }
       - raw-window-handle = "0.6"
    
    4. [workspace.lints.rust] with unsafe_code = "deny"
    
    5. [profile.release] with optimizations: opt-level = 3, lto = true, strip = true

    Reference RESEARCH.md lines 244-279 for exact patterns.
