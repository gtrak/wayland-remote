  <name>Task 1: Implement client connection handler</name>
  <files>crates/server/src/streaming/client.rs</files>
  <action>
Create client.rs for handling individual viewer connections:

1. Create handle_client(socket: TcpStream, state: StreamingState) async function
2. Implement bounded mpsc channel for backpressure:
   - let (tx, rx) = mpsc::channel::<Vec<u8>>(32); // 32 frame buffer
3. Read loop: use socket.read() to handle incoming viewer requests
4. Write loop: stream frames from rx channel using encode_frame()
5. Graceful disconnect handling:
   - On Ok(_) - client disconnected normally
   - On Err(e) - log debug, cleanup happens via task cancel
6. Add client to StreamingState.clients map on connect
7. Remove from clients map on disconnect

Reference RESEARCH.md Pitfall 4: Use try_send() for backpressure, log warning on drop.
  </action>
