  <name>Task 2: Implement RGBA extraction using ExportMem trait</name>
  <files>crates/server/src/rendering/pixel_export.rs</files>
  <action>
    Implement extract_rgba_pixels using Smithay's ExportMem trait:
    
    Implementation steps:
    1. Import the surface texture using renderer.import_surface(surface)
       or get texture from surface via with_states
    2. Call renderer.copy_framebuffer(texture, Fourcc::Abgr8888, None)
       to copy to PixmanMapping
    3. Call renderer.map_texture(&mapping) to get &[u8] RGBA slice
    4. Clone bytes into Vec<u8> (we need owned data for sending)
    5. Return RgbaData with dimensions and cloned data
    
    Important: Hold the mapping reference until data is cloned. Format is Abgr8888.
    
    Return None if extraction fails (surface has no buffer, etc.).
  </action>
