# Plan 06-01: WindowManager Core

**Create WindowManager struct with bidirectional HashMap mappings for tracking multiple DisplayWindow instances**

## Must-Haves

### Truths
- Each Wayland surface creates a corresponding Windows HWND
- Multiple windows can be tracked simultaneously
- Frames route to correct window by window_id
- Events route to correct window via reverse lookup

### Artifacts
- `crates/viewer/src/window_manager.rs` - WindowManager struct and implementation
- Modified `crates/viewer/src/lib.rs` - Export window_manager module

### Key Links
- `WindowManager::get_or_create_window()` -> creates/retrieves window
- `WindowManager::get_window()` -> routes frames to window
- `WindowManager::get_window_id()` -> routes events via reverse lookup
