# Plan 06-02: ViewerApp Multi-Window Integration

**Integrate WindowManager into ViewerApp, replacing Option<DisplayWindow> with multi-window support**

## Must-Haves

### Truths
- ViewerApp tracks multiple windows instead of single optional window
- First frame for each window_id triggers window creation
- Frames route to correct window automatically
- Window events route to correct window via reverse mapping

### Artifacts
- Modified `crates/viewer/src/app.rs` - Multi-window ViewerApp

### Key Links
- `process_frames()` -> get_or_create_window() per frame
- `window_event()` -> get_window_id() for reverse lookup
- `resumed()` -> no longer creates window (lazy creation)
