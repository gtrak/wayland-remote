# Plan 06-04: Window Lifecycle Management

**Implement window close events, cleanup, and cascading positions for multi-window viewer**

## Must-Haves

### Truths
- User can close individual windows without affecting others
- Application exits when all windows are closed
- New windows appear at cascading positions (not stacked)
- Proper cleanup when windows are removed

### Artifacts
- Modified `crates/viewer/src/window_manager.rs` - is_empty(), cascading positions
- Modified `crates/viewer/src/app.rs` - CloseRequested handling, exit logic

### Key Links
- `WindowEvent::CloseRequested` -> remove_window() -> cleanup
- `window_manager.is_empty()` -> event_loop.exit()
- `create_window()` -> cascading position calculation
