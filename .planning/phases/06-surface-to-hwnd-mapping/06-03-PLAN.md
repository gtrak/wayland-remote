# Plan 06-03: Window Resize Handling

**Implement per-window resize handling with 10% threshold and aspect ratio preservation**

## Must-Haves

### Truths
- User can resize windows and content scales properly
- Content maintains aspect ratio during resize
- Each window independently tracks its resize threshold
- No resize feedback loops (flickering)

### Artifacts
- Modified `crates/viewer/src/app.rs` - Resize event routing
- Modified `crates/viewer/src/display/window.rs` - Per-window threshold
- Verified `crates/viewer/src/display/gdi.rs` - Aspect ratio preservation

### Key Links
- `WindowEvent::Resized` -> get_window_id() -> window.handle_resize()
- `DisplayWindow::submit_frame()` -> 10% threshold check
- `StretchDIBits()` -> aspect ratio preserved via dest rect
